# 001. D.one 매거진 템플릿 규격 확정 — 2026-10-05

## 결정

매거진의 모든 페이지 위치·크기·색상은 `shared/spec.js`의 `SPEC` 한곳에서만 정의한다.
`shared/scene.js`(미리보기·PNG export·Figma export 공용)와 원고 생성 프롬프트(`server/codex.js`)는 이 값을 읽어서 쓴다.
`tests/spec.test.js`가 모든 값을 고정하므로, 규격을 바꾸려면 `SPEC`과 테스트를 함께 고쳐야 한다.

## 배경

표지 그라데이션, 로고 위치, 사진 아래형 헤더 등을 여러 차례 조정하면서 수치가 `scene.js` 곳곳에 흩어졌고,
표지 제목 위치는 `max(880, min(1050, 1290−높이)) − 40`처럼 보정값이 덧붙은 형태가 되었다.
다른 기능을 고치다가 규격이 의도치 않게 바뀌는 것을 막기 위해 한곳에 모으고 테스트로 고정했다.
정리 전후로 표본 80페이지의 렌더링 결과(SVG와 노드 좌표)가 동일함을 확인했다.

### 원고 생성 규칙

- 원문 근거를 지킨 편집자의 분명한 주장과 다양한 문장 리듬. 통념 반박·선택의 대가·독자 도발의 서로 다른 표지 제목 후보 정확히 3개.
- 제목 16자 이내, 본문 카드당 약 100~180자, 본문 카드 4~9개(표지·엔딩 제외). 짧은 자료 4장, 여러 사례·논점 5~6장, 풍부한 긴 자료 7~9장. 반복·인사·광고를 제외한 실질 내용량으로 정한다.
- 원문이 1, 2, 3 / 첫째·둘째 / 1단계처럼 번호로 진행하면 기사 관점에 관련된 항목의 번호와 순서를 그대로 살려 `N. 소제목` 형태의 카드 제목을 만든다.

## 규격을 바꾸는 방법

1. `shared/spec.js`의 값을 바꾼다.
2. `tests/spec.test.js`의 고정값을 같은 값으로 바꾼다.
3. 이 문서의 표를 갱신한다.
4. `npm test` 통과 후, 실행 중인 4317 서버를 재시작하고 `/api/export/png`로 실제 PNG를 확인한다.

## 관련 파일

- `shared/spec.js` — 규격 값

- `shared/templates.js` — 템플릿 순서
- `tests/spec.test.js` — 규격 고정 테스트
